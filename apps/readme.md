# 目录说明
1. 本目录用于存放各个应用规则/全局规则，更新订阅内容仅需修改此处后actions即可
1. 每个应用规则文件内必须以 ```json5 为开头字段，用于规范内容格式，或者可以无开头字段。否则actions创建订阅文件时会出错或产出错误内容
1. actions构建时不限制本目录内所有规则文件具体文件名，但必须以`.md`为扩展名
