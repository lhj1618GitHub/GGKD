 **相对目标节点位置** ：left top right bottom 

1.参考matches计算
```text
position: 
{
   left: 'width * 0.5',
   top: 'height * 0.5',
},
```
2.参考matches中心点偏移
```text
position: 
{
   left: '50',
   top: '100',
},
```

 **绝对位置** ：x - 距离屏幕左侧的距离 ； y - 距离屏幕顶部的距离

- 屏幕中心
```text
position:
{
 x: 'screenWidth/2',
 y: 'screenHeight/2',
}
```

- 指定屏幕坐标
```text
position:
{
 x: '500',
 y: '1500',
}
```
