# 字符串操作符语法快速记忆

## 1️⃣ 分类 + 联想

把这些操作符分成三类：

| 类别                   | 正符号                    | 含义       | 记忆技巧                                                     |
| ---------------------- | ------------------------- | ---------- | ------------------------------------------------------------ |
| **等于 / 完全匹配**    | `=`                       | 完全匹配   | 就像数学里的等号 = 完全相等                                  |
| **包含 / 开头 / 结尾** | `^=`、`$=`、`*=`          | 字符串操作 | 看符号直觉记：- `^` → 顶 → 开头- `$` → 底 → 结尾- `*` → 星星 → 任意 → 包含 |
| **取反 / 不匹配**      | `!=`、`!^=`、`!$=`、`!*=` | 不匹配     | 在符号前加 `!` → 表示 “不”                                   |

------

## 2️⃣ 联想口诀

可以用一个 **口决顺序** 记：

> **等号对齐，顶底星随意，前加惊叹反过来**

- 等号 = 完全匹配
- `^=` 顶 → 开头
- `$=` 底 → 结尾
- `*=` 星 → 任意 → 包含
- 惊叹号 `!` → 反向，不匹配

------

## 3️⃣ 举例记忆

| 例子            | 操作符 | 意义         | 联想                     |
| --------------- | ------ | ------------ | ------------------------ |
| `text="跳过"`   | `=`    | 完全匹配     | 就像数学里的 a = a       |
| `text^="跳过"`  | `^=`   | 开头是跳过   | 顶端开始，顶 ^           |
| `text$="秒"`    | `$=`   | 结尾是秒     | 底部结束，底 $           |
| `text*="广告"`  | `*=`   | 包含广告     | 星星代表任意位置都可以有 |
| `text!="跳过"`  | `!=`   | 不等于跳过   | 惊叹号 → 否定            |
| `text!^="跳过"` | `!^=`  | 不以跳过开头 | 顶端排除                 |
| `text!$="秒"`   | `!$=`  | 不以秒结尾   | 底部排除                 |
| `text!*="广告"` | `!*=`  | 不包含广告   | 星星排除                 |

------

✅ **关键技巧**：

- 想开头？看顶端 → `^=`

- 想结尾？看底部 → `$=`

- 想包含？看星星 → `*=`

- 想取反？加 `!
